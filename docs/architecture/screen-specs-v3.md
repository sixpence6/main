## 0 替代声明与使用规则

**替代声明**：本文件取代 `frontend-design-v3.md` §1.1 的全部视觉起始值（`#EEF0F8`/`#5846E8`/288/68/880/圆角 28 等），并取代原型 `variant-a.css` 的具体像素值（8.5–9px 元信息、304px 抽屉、620px 断点、19px 确认卡圆角等）。两份旧材料只保留观感参考价值。

**使用规则**（每条都是验收判据）：

1. 每个数值必须是令牌名。确实没有对应令牌时，写明理由并在 §11 登记候选令牌，不得直接写死 hex/px。
2. 不新增颜色；不新增 alpha 通道（仅 `--surface-glass` 与 `--scrim` 例外）；字号下限 12px（代码块与 ID 的 13px 唯一例外）；字重只用 400/500/600。
3. 状态一律「图标 + 文字 + 颜色」三重表达，颜色永不作为唯一线索。
4. 每个状态必须给出 320 / 768 / 1440 三档行为；三档只改内边距、顶栏高与侧栏形态，不改颜色、圆角、阴影、字号。
5. 焦点一律 2px 实色环 + 2px offset：浅底 `--focus-ring-light`，深色壳 `--focus-ring-dark`；禁止 `outline: 0`，禁止只用一像素边框表达焦点。
6. 验收以「真实浏览器 + 步骤 + 结果 + 关联事实」为准；静态截图、DOM 快照或代码审查不能单独签字。
7. 深色壳（侧栏、顶栏）不使用语义色，一律银灰文字 + 图标 + 文案；语义色只出现在浅色消息流内。
8. 文案沿用现有契约字符串（如「正在读取对话…」「提示词检查中…」「确认使用以上提示词生成」「处理中…」「复制提示词/已复制」「有新内容，回到底部」「重试」），本文不发明新文案；`§2.2` 推荐提示词是唯一新增文案，属空态本地常量。

## 1 全局层

### 1.1 壳体与顶栏

| 项 | 规格 |
| --- | --- |
| 结构 | 全出血两列：左 `--sidebar-width`（264）深色侧栏，右主画布；顶栏 `--topbar-height`（48，<768 为 44）横跨右侧，或横跨整宽（≥1024 时侧栏自有品牌区，顶栏只覆盖主画布右侧，见 `design-tokens-v3.md` §7.1） |
| 画布 | `--surface-canvas`；无 12px 外壳外边距、无白卡、无 `--radius-shell` |
| 侧栏 | `--surface-shell`；品牌区 48 与顶栏等高；搜索 + 分组 + 用户块；会话行 36、`--radius-sm`、左右 12；选中 = `--surface-shell-active` + 左 2px `--text-inverse-secondary` 竖条 + 标题升 `--text-inverse-primary`（三重表达） |
| 顶栏 | 深色 `--surface-shell`，下缘 1px `--line-inverse`；左侧品牌/面包屑，右侧状态胶囊（见 1.2） |
| 内容列 | `min(760px, 100%)` 居中；结果类资产上限 `1120px`（灯箱与结果页共用） |

三档：`<768` 内边距 16、顶栏 44、侧栏为抽屉；`768–1023` 内边距 24、顶栏 48、侧栏仍为抽屉；`≥1024` 内边距 24（≥1280 变 32）、侧栏 264 常驻。

**768×1024 必须只有一套顶栏**：移动顶栏（52px 现状）与桌面顶栏不得同时出现（现行断点崖，实现时修掉）。

### 1.2 状态胶囊（CurrentStatusCapsule）

- 结构：图标 16 + 文案 `--text-caption` 12/18 500 + 可选时间（tabular-nums）；高度 24；`--radius-pill`。
- **≥768**：位于顶栏右端（内缩 16），深色底 `--surface-shell-active` + 1px `--line-inverse` + `--text-inverse-secondary`；五种 tone 只靠图标形状 + 文案区分（进行中/待确认/已完成/需要处理/失败），不使用语义色。
- **<768**：离开顶栏，作为页面头部之后、消息流之前的流内元素，左对齐；浅底 `--surface-panel` + 1px `--line-hairline`，此时允许语义色三重表达。
- 动效：仅 tone 切换时 120ms 透明度/颜色；**删除呼吸动画、渐变、多层阴影**（现行实现债务）。
- 不遮挡内容：任何视口下都不得覆盖标题、消息或输入区。
- 无障碍：`role="status"`、`aria-live="polite"`；同一进度不得被重复播报（`frontend-design-v3.md` §3.1 要求）。

### 1.3 新内容浮标（newContentAvailable）

- 位置：消息流底部、输入区上方 `--space-3` 处，水平居中。
- 样式：`--surface-panel` + 1px `--line-hairline` + `--radius-pill` + `--shadow-composer`；`--text-caption` 12/18 `--text-secondary`；内边距 8/14。
- 交互：点击滚到底部；出现/消失 180ms 透明度，reduced-motion 直接切换。

### 1.4 会话失效横幅（session lost）

- 位置：顶栏下方，整条全宽，不浮动、不覆盖消息。
- 样式：`--surface-inset` 底 + 下缘 1px `--line-hairline` + danger 图标 + `--text-body` 正文 + 文本链接「重新登录」；高 ≥44，内边距 12/16。
- 不做模态、不锁滚动；键盘可达。

### 1.5 焦点、滚动与动效

- 焦点顺序：侧栏 → 顶栏动作 → 消息区 → 输入区；抽屉与灯箱打开时焦点移入容器（`aria-modal`），关闭后回到触发元素。
- 滚动容器：消息流唯一滚动区；滚动条 8px，thumb `--line-hairline`，hover `--line-hover`；深色壳 thumb `--line-inverse`。
- 动效只允许 `--dur-fast` 120（颜色/透明度）、`--dur-base` 180（展开/淡入）、`--dur-slow` 240（抽屉/整块位移），曲线 `--ease-out`；禁止回弹、循环、呼吸、自动播放。
- `prefers-reduced-motion: reduce`：取消位移与缩放，只保留 ≤120ms 透明度；抽屉与灯箱直接出现。

## 2 空态与连接状态

### 2.0 状态矩阵

| 子状态 | 触发条件 | 备注 |
| --- | --- | --- |
| 新建对话空态 | `!hasConversation`（URL 无 `projectParam`） | 含推荐提示词 |
| 读取中 | `projectLoading` | 文字型 loading，无骨架 |
| 读取失败 | `projectError` | 行内块 + 重试 |

会话已存在但消息为空**不显示欢迎语**，直接渲染消息流（现行行为，保持）。

### 2.1 新建对话空态

- **触发**：`/` 且没有项目参数。
- **层级与结构**：主画布 → 空态容器 →（标题、说明、推荐提示词列表）→ 输入区。
- **布局与留白**：容器 `min(760px,100%)` 居中，垂直起点约视口 38%，左右内边距沿用页面内边距；标题与说明间距 `--space-3`；说明与提示词列表间距 `--space-8`；提示词行间距 `--space-2`。320：起点 30%，列表纵排；768：同；1440：同。
- **颜色**：标题 `--text-primary`；说明 `--text-secondary`；提示词行 `--surface-panel` 底 + 1px `--line-hairline`，hover 只把边框换 `--line-hover`（不加阴影、不位移）。
- **字体**：标题 `--text-display`（320 取 26px 下限，1440 最大 40px）；说明 `--text-reading` 15/25；提示词 `--text-body` 14/22 500。
- **交互与动效**：首屏输入区自动聚焦一次，无动画；提示词行整行可点，点击把文案填入输入区草稿并聚焦文本域（**不自动发送**）；输入区有草稿时整块推荐列表隐藏（避免与技术内容争抢）。
- **验收检查点**：320/768/1440 各一张新建对话截图；点击任一提示词后输入区出现同一文案、焦点在文本域、未发出请求；草稿非空时列表消失。

### 2.2 推荐提示词（唯一新增文案）

- 数量固定 3 条；前端静态常量，不走 API、不缓存、不个性化。
- 默认文案（可整体替换；替换时同步更新本节与 T19 验收）：
  1. 「把这张产品图换成秋日户外场景，保留包装质感」
  2. 「为这组新品生成一张极简台面主图，冷白背景」
  3. 「做一张 1:1 促销主视觉，石墨黑底，留出价格位置」
- 布局：≥768 三列等宽（gap `--space-3`），<768 纵排单列全宽；每行最小高 44，内边距 12/16。
- 键盘：Tab 可逐个到达，Enter/Space 触发填入；焦点环 2px + offset 2（不得被列表容器裁切）。

### 2.3 读取中

- **触发**：`projectLoading`。
- **层级与结构**：消息流区域内单行居中文字。
- **布局**：垂直留白 `--space-10`（48）上下；320/768/1440 相同。
- **颜色/字体**：`--text-muted`，`--text-caption` 12/18。
- **交互**：无 spinner、无骨架闪烁、无动画；`role="status"`。
- **验收**：慢网络下截到该行；页面无布局跳动（加载前后消息列宽一致）。

### 2.4 读取失败

- **触发**：`projectError`。
- **层级与结构**：消息流区域内行内块：图标 + 一句话 + 重试按钮。
- **布局**：块最大宽 640，居中，内边距 16/20（`--space-4`/`--space-5`）；320 全宽。
- **颜色**：`--surface-inset` 底；danger 图标；正文 `--text-secondary`；按钮为文本按钮 `--action-link`。
- **字体**：正文 `--text-body` 14/22。
- **交互**：重试触发原 `retry`；失败原因不展开技术栈信息（保留现有文案契约）。
- **验收**：构造 401/500 两例，截图 + 网络请求记录；点重试后发起一次请求、按钮不重复触发（禁用至返回）。

## 3 消息流

### 3.0 状态矩阵

| 子状态 | 触发条件 |
| --- | --- |
| 用户消息 | `role=user` |
| 助手消息 | `role=assistant` |
| 附件缩略图 | 消息带参考图 |
| 代码块 | 消息含代码 |
| 发送中 | 消息未落库/待确认前 |
| 需求确认卡 | `canConfirmRequirements` |
| 提示词确认卡 | `promptPreview`（见 §4） |
| 任务/执行块 | `taskStatusText` 或 `taskActions`（见 §5） |
| 结果不可用块 | `resultUnavailableText`（见 §5.4） |
| 图片历史 | `imageHistory.length`（见 §6） |

### 3.1 用户消息

- **层级**：消息组内单条；meta 行在上，气泡在下。
- **布局**：右对齐；气泡 `max-width: 78%`（320 下 ≈224px）；内边距 12/16；消息间距：同角色 12、换角色 24；无分割线。
- **颜色**：气泡 `--surface-inset` 底 + 1px `--line-hairline`；正文 `--text-primary`。
- **字体**：正文 `--text-reading` 15/25；meta `--text-caption` 12/18 `--text-muted`（「你 · HH:mm」）。
- **交互**：不设 hover 态、不加阴影；文本可选中复制。
- **验收**：三档截图；长段落换行不溢出、气泡不被 760 列裁切；320 下 78% 生效。

### 3.2 助手消息

- **层级**：不套气泡，直接排在画布上。
- **布局**：占列宽 92%；内边距 0；与相邻消息间距同 3.1。
- **颜色/字体**：正文 `--text-primary` `--text-reading`；meta 同 3.1（「智能生图助手 · HH:mm」）。
- **交互**：无 hover；长正文正常换行。
- **验收**：三档截图；与用户消息的视觉层级可一眼区分（不靠背景色块）。

### 3.3 附件缩略图

- **布局**：贴气泡内下方，34×42，右侧留 6 间距；一行最多 4 个，超出换行。
- **颜色/字体**：`--surface-media` 底、`--radius-sm`；文件名 `--text-caption` `--text-secondary`，单行省略。
- **交互**：点击打开灯箱（复用 §6.6）；键盘可达（Tab + Enter）。
- **验收**：320 三张缩略图不挤压正文；Enter 打开灯箱、Esc 关闭后焦点回缩略图。

### 3.4 代码块（唯一允许 13px）

- **布局**：块内边距 12/16，横向可滚动。
- **颜色/字体**：`--surface-inset` 底、`--radius-sm`、`--font-mono` 13/20。
- **验收**：320 无整页横向滚动（块内滚动即可）。

### 3.5 发送中

- **表达**：只在 meta 行追加「发送中…」，`--text-caption` `--text-muted`。
- **禁止**：气泡变灰、整块降透明度、闪烁气泡。
- **验收**：弱网窗口期截图；消息落库后文案消失、位置不跳。

### 3.6 需求确认卡

- **触发**：`canConfirmRequirements`。
- **层级与结构**：卡片 → 标题 → 摘要正文 → 主 CTA。
- **布局**：卡片与消息同列宽；内边距 16；卡片上下间距 24。
- **颜色/字体**：`--surface-panel` + 1px `--line-hairline` + `--radius-md`；标题 `--text-section` 17/24 600；正文 `--text-reading`；主按钮同 §7.4。
- **交互**：单主按钮；提交后卡片转只读（按钮区换为状态行）。
- **验收**：三档截图 + 点击后请求记录；重复点击被禁用。

## 4 提示词确认卡

### 4.0 状态矩阵

| 子状态 | 触发条件 | 关键差异 |
| --- | --- | --- |
| 待确认 | `can_confirm=true` | 主 CTA 可用 + 复制全文 |
| 检查中 | `can_confirm=false` | CTA 禁用，文案「提示词检查中…」 |
| 已复制 | `copied=true` | 按钮文案「已复制」2s |
| 已确认转执行中 | 提交后 | 动作区收起，正文转只读 |
| 超长 | 正文高度 > 480 | 内部滚动，动作区吸底 |

「确认失效」不是卡片状态：由 §5.4 结果不可用块表达（现行行为，保持）。

### 4.1 待确认

- **层级**：卡片 → 标题行（标题 + 版本号 + 状态胶囊）→ 引用块正文 → 负面块（有则显示）→ 事实行 → 动作区。
- **布局**：卡片内边距 16，`--radius-md`；正文引用块内边距 14/16；事实行 `--space-4` 分隔；动作区上边距 `--space-4`。320：事实两列、CTA 全宽；≥768：事实四列、CTA 行内右对齐。
- **颜色**：`--surface-panel` + 1px `--line-hairline`；引用块 `--surface-inset` 底 + 左 2px `--line-hover` 竖线 + `0 8 8 0` 圆角；状态胶囊 warning 三重表达；负面块 `--surface-inset` + danger 图标 + `--text-caption` 标签「避免」。
- **字体**：标题 `--text-section` 17/24 600；版本号 `--font-mono` 13/20 `--text-muted`；正文 `--text-reading` 15/25；事实 `dt` `--text-caption` `--text-muted`、`dd` `--text-body`。
- **交互**：主 CTA「确认使用以上提示词生成」高 36、`--radius-sm`、墨色底；次按钮「复制提示词」幽灵；复制成功切「已复制」2s 后复原，不弹 toast；CTA 提交后立即禁用（防连点）。
- **验收**：三档截图；点击复制后剪贴板内容与卡片正文一致（用 CDP 读剪贴板）；点击 CTA 只有一次请求。

### 4.2 检查中

- CTA 禁用态：`--surface-inset` 底 + `--text-muted` 文字，**不降低整块透明度**；文案「提示词检查中…」。
- 复制按钮保持可用（复制不受检查阻塞）。
- 验收：截图 + 后端慢响应时按钮不可点；检查结束后无需刷新即恢复。

### 4.3 已确认转执行中

- 动作区收起，卡片底部追加执行状态行（§5.1）；正文转只读（不可编辑本就成立），卡片不加「已完成」装饰。
- 验收：提交后 3s 内截图；卡片不重排、不跳动。

### 4.4 超长正文

- 正文容器 `max-height: 480px`，内部滚动（滚动条按 §1.5）；动作区吸底（`position: sticky; bottom: 0` + `--surface-panel` 底）。
- 验收：320 超长提示词下 CTA 始终可见，内部滚动不带动页面。

## 5 执行、失败与恢复

### 5.0 状态矩阵

| 子状态 | 触发条件 |
| --- | --- |
| 执行中 | `isWorkingStatus` / `taskStatusText` |
| 需勾选确认 | `requires_confirmation` 动作未勾选 → 禁发送 |
| 失败 | 任务失败且可恢复（三类 recoverable 标志） |
| 结果未知 | 远端提交/结果未知 |
| 恢复后 | 恢复动作完成，原块原地更新 |

### 5.1 执行中

- **层级与结构**：消息流内一条状态行（不新增消息）：图标 + 文案 + 可选操作。
- **布局**：与相邻消息同列，内边距 12/16；320 全宽。
- **颜色/字体**：`--surface-inset` 底 + `--radius-md`；info 图标 + `--text-body` 14/22 `--text-secondary`。
- **交互**：静止，不呼吸、不做打字点循环动画（reduced-motion 下连淡入也取消）；不显示百分比、不显示内部阶段（`frontend-design-v3.md` §3.1）。
- **验收**：执行期截图；无进度百分比、无重复状态消息；reduced-motion 下无动画。

### 5.2 需勾选确认

- 动作项带复选框，未勾选时发送按钮禁用（§7.3）；复选框 20×20、`--radius-sm`、1px `--line-control`，选中墨色底 + 对勾 16。
- 验收：未勾选点击发送无请求；勾选后可发送；键盘 Space 可切换。

### 5.3 失败

- **层级**：原执行块原地替换为失败块：图标 + 一句话原因 +（可选）恢复按钮。
- **布局**：内边距 12/16；按钮行上边距 `--space-3`。
- **颜色**：`--surface-inset` 底；danger 图标；正文 `--text-secondary`；恢复按钮幽灵样式。
- **交互**：恢复入口仅在服务端允许时出现；**不自动重试、不自动重生成**；点击后该块转为执行中。
- **验收**：受控适配器制造失败，截图 + 后端事实（run id + 错误码）；页面不自动发起新请求。

### 5.4 结果未知 / 结果不可用

- 未知：中性 info 图标 + 「结果未知，正在核实」+ 仅「核实/找回」动作；不提供「取消」宣称（`frontend-design-v3.md` §3.3）。
- 不可用：`resultUnavailableText` 现有语义（已撤销 / 已发布但无 asset）；`--surface-inset` + 图标 + `--text-secondary`；不静默换图、不自动重生成。
- 验收：两例各一张截图 + 后端事实；不得出现「已取消」类文案。

### 5.5 恢复后

- 原块原地更新为成功态（不追加新消息）；状态胶囊同步更新；成功后不重复播报。
- 验收：恢复前后同一位置截图对照（元素位置不变）。

## 6 图片结果卡与灯箱

### 6.0 状态矩阵

| 子状态 | 触发条件 |
| --- | --- |
| 单图卡 | 历史 1 条 |
| 多图栅格 | ≥2 条 |
| 当前版 / 历史版 | `is-current` / `isLatest` |
| 不可用图 | 无 `assetId` |
| 下载禁用 | `!canDownload` |
| 灯箱 | `lightboxOpen` |

### 6.1 结果卡

- **层级**：卡片 → 媒体区 → 标题/元信息 → 动作行。
- **布局**：卡片内边距 12；图 3:4；动作行上边距 `--space-3`。多图：≥768 两列（gap 16），<768 单列；320 一卡一图不溢出。
- **颜色**：`--surface-panel` + 1px `--line-hairline` + `--radius-md`；媒体底 `--surface-media`、`--radius-sm`；hover 只换 `--line-hover`，不加阴影、不位移、不缩放；焦点环画在卡片外沿 offset 2。
- **字体**：标题 `--text-body` 14/22 500；来源/尺寸 `--text-caption` `--text-muted`；版本徽标 `--text-caption` + `--radius-pill`（`--surface-panel` 底 + hairline，不叠阴影）。
- **交互**：整卡可点开灯箱；下载按钮禁用态（`--text-muted` + 不缩透明）；版本切换不刷新整页。
- **验收**：三档截图；hover 无位移；320 单列；当前版/历史版徽标在三档下都可读（12px）。

### 6.2 不可用图

- `--surface-inset` 底 + `--radius-sm` + 图标 + 一行 `--text-secondary`（不用灰色渐变、不降透明度）。
- 验收：截图 + 该图记录的 asset 状态事实。

### 6.3 灯箱（居中覆盖式，显著变更）

现状是右侧抽屉；本规格改为**居中灯箱**，理由是 3:4 结果图在抽屉里宽度不足 400px。

- **层级与结构**：`Teleport` 到 body；遮罩 → 内容容器 → 图片 → 关闭按钮。
- **布局**：居中；容器内边距 12；图片 `max-width: min(92vw, 1120px)`、`max-height: 86vh`，保持比例；320 下容器内边距 8、边距 16。
- **颜色**：遮罩 `--scrim`（保持 `.4`，不新增更深遮罩）；容器 `--surface-panel` + `--shadow-overlay` + `--radius-lg`。
- **字体**：灯箱内不放文字说明（版本信息留在卡上）。
- **交互与动效**：
  - 打开：焦点移入关闭按钮；`role="dialog"` + `aria-modal="true"`；背景 `inert` + 滚动锁。
  - 关闭：Esc、点遮罩、点关闭按钮三条路径；关闭后焦点回原图卡。
  - 关闭按钮 44×44，置于容器右上（内缩 8），`--radius-sm`，图标 20。
  - 过渡 180ms 透明度（reduced-motion 直接出现）；不做缩放手势、不做滑动切图。
- **验收**：三档截图（320 竖屏）；Tab 只在关闭按钮内循环；三条关闭路径都回焦；背景不可滚动、不可点击；`aria-modal` 可用 axe/无障碍树确认。

## 7 输入区

### 7.0 状态矩阵

| 子状态 | 触发条件 |
| --- | --- |
| 空闲 / 聚焦 | 默认 |
| 中文组字 | `composing` |
| 附件待发送 / 上传中 | `pendingAttachment` / `attachmentBusy` |
| 阻塞（生成中） | `busy` |
| 错误横幅 | `flowError` / `attachmentError` |
| 修改模式提示 | `pendingTaskAction` |
| 窄屏贴底 | <768 |

### 7.1 容器与文本域

- **布局**：容器 `--surface-panel` + 1px `--line-hairline` + `--radius-md` + `--shadow-composer`，内边距 12/16；文本域最小高 44、最多 6 行后内部滚动；<768 贴底，`padding-bottom: max(--space-3, env(safe-area-inset-bottom))`。
- **字体**：`--text-reading` 15/25；占位 `--text-muted`。
- **聚焦**：文本域 `:focus-visible` 2px `--focus-ring-light` + offset 2，同时容器边框转 `--line-control`；不得只用光晕或 1px 边框（现行 2.50:1 作废）。
- **验收**：三档截图；320 软键盘弹出后输入区不被遮挡（真机或设备模拟）；聚焦环可见。

### 7.2 发送按钮与快捷键

- 36×36、`--radius-sm`、墨色底 + `--text-inverse-primary` 图标；空内容/重复/忙时禁用（`--surface-inset` 底 + `--text-muted`），**不降整体透明度**。
- Enter 发送、Shift+Enter 换行、Ctrl/⌘+Enter 也可发送、中文组字中 Enter 不发送（`frontend-design-v3.md` §6.1）。
- 验收：IME composition 期间 Enter 无请求；空内容发送按钮不可点。

### 7.3 生成中（阻塞）

- 发送按钮禁用并显示「处理中…」（保留现有文案）；文本域仍可编辑（草稿保留），仅不可提交；一行 `--text-caption` `--text-muted` 提示「正在生成，完成后可发送」。
- 验收：生成期输入文本、按钮不可点、无排队请求；结束后草稿仍在。

### 7.4 附件预览

- 缩略图 34×42、`--radius-sm`、`--surface-media`；文件名 `--text-caption`；删除按钮 24×24（≥768 hover 显形，<768 常显）。
- 上传中：文件名位置显示「上传中…」；失败：danger 图标 + 重试。
- 验收：上传中截图；删除后附件消失且不发送。

### 7.5 错误与模式横幅

- `flowError` / `attachmentError`：容器上方行内条，`--surface-inset` + hairline + `--radius-md`，内边距 8/12，图标 + `--text-body` + 文本按钮「重试」。
- 修改模式：`--action-soft` 底 + info 图标 + 一句说明 + 取消入口。
- 验收：各一条截图；横幅出现不推挤输入框高度。

### 8.1 抽屉
