# R3 T24 品牌登录与个人／管理页面操作说明

- Issue: #76
- 适用版本: integration/v3 492989f 之后的 #76 代码提交
- 页面: 登录、一次性链接设置密码、账号安全、管理员账号
- 状态: 通过（R3 T24 阶段条件）

## 1. 目的与边界

本说明覆盖普通账号和管理员在一个项目实例内的日常账号操作：登录、首次设置或重置密码、修改本人密码、查看并撤销本人会话、查看本人安全事件，以及管理员创建账号、停用／恢复、签发一次性链接和查看配额。

页面不提供自助注册、邮件发送、第三方登录、MFA、账号删除、邮箱修改或角色提升。系统不会通过聊天、电话、工单或邮件索要密码；管理员也无法查看用户的旧链接或明文密码。

权限、会话、链接一次性、限流和审计由服务端执行；本说明中的页面按钮不会把无权操作变为有权操作。

## 2. 用户路径

### 2.1 普通用户登录

1. 打开 /login。
2. 输入管理员为你创建的邮箱地址；浏览器或密码管理器可使用 username 自动填充。
3. 输入本人密码；密码区分大小写，可使用浏览器或密码管理器自动填充。
4. 需要核对输入时，点击密码框右侧的显示按钮；再次点击隐藏。
5. 点击登录。成功后进入工作台；失败时按页面提示处理，不重复快速尝试。

### 2.2 首次设置密码或重置密码

1. 向管理员获取一次性链接。链接通常通过受控渠道交付，不由系统发送邮件。
2. 打开链接，页面先核实链接状态；核实阶段不会设置密码。
3. 链接有效时，输入新密码和确认密码。密码至少 15 个 Unicode 码点、最多 128 个 Unicode 码点，允许空格，不会自动截断。
4. 实时要求列表会标记已满足项；两次输入不一致或长度不足时，字段下方显示关联错误。
5. 点击设置密码。成功后旧密码、旧会话和其他未使用链接失效；页面清空字段并移除地址中的 token。
6. 使用新密码重新登录。系统不会自动登录，也不会把密码写入本地存储。

### 2.3 修改本人密码与查看会话

1. 打开 /account/security，或从工作台进入账号安全。
2. 在修改密码区域填写当前密码、新密码和确认新密码；三个字段均支持显示／隐藏和自动填充。
3. 点击修改密码。成功后会撤销全部会话和未使用链接，需要用新密码重新登录。
4. 会话区域列出当前账号的活动会话；可撤销指定会话，或点击撤销其他会话。
5. 安全事件区域显示本人可读事件；点击刷新重新读取，不修改事件。

### 2.4 管理员创建与维护账号

1. 以管理员身份打开 /admin/accounts。
2. 在创建账号输入邮箱，点击创建。新账号为待设置密码状态，不会获得默认密码；邮箱必须唯一。
3. 在账号行点击签发链接，选择用途（首次设置或重置），确认目标账号。链接只显示一次，关闭后无法再次查看，只能重新签发。
4. 对需要暂停使用的账号点击停用；停用会撤销其会话和未使用链接。恢复后旧密码不会复活，待设置账号仍需完成设置流程。
5. 在配额面板查看或调整实例／账号生成限制；调整会记录前后值。
6. 窄屏下账号表变为卡片，字段通过 data-label 标识，操作按钮全宽排列。

## 3. 页面状态与按钮

| 页面 | 状态 | 用户可见行为 |
| --- | --- | --- |
| 登录 | 默认 | 邮箱、密码、显示／隐藏、登录；帮助区说明联系管理员 |
| 登录 | 提交中 | 按钮显示正在登录…并禁用，避免重复提交 |
| 登录 | 失败 | 通用凭据错误、限流提示或服务不可用提示；错误与字段关联 |
| 设置密码 | 核实中 | 正在核实链接…；只读取状态 |
| 设置密码 | 链接不可用 | 链接不可用说明、30 分钟／一次性帮助、返回登录 |
| 设置密码 | 可设置 | 新密码、确认密码、实时策略、设置密码 |
| 设置密码 | 成功 | 密码已设置成功，请使用新密码登录；前往登录 |
| 账号安全 | 默认 | 账号信息、修改密码、会话、安全事件、联系管理员帮助 |
| 管理员 | 默认 | 汇总、创建账号、账号表、签发链接、停用／恢复、配额、事件 |
| 管理员 | 链接弹窗 | 目标账号与用途、一次性链接、仅显示一次提示；Escape 关闭 |

## 5. 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 登录提示凭据无效 | 邮箱拼写、密码大小写或账号未设置完成 | 核对邮箱；确认管理员已签发链接并完成设置；不要反复尝试以免触发限流 |
| 提示尝试过多 | 账号或来源触发限流 | 等待窗口结束；联系管理员确认账号状态 |
| 提示服务暂不可用 | 认证资源繁忙或服务异常 | 稍后重试；持续失败时由维护者查看服务日志 |
| 设置密码页显示链接不可用 | 链接过期、已使用或被新链接替代 | 请管理员重新签发一次性链接 |
| 设置成功但无法登录 | 使用了旧密码或输入法带入多余字符 | 使用新密码；检查大小写和空格；仍失败时联系管理员 |
| 修改密码后其他设备退出 | 这是预期的全会话撤销 | 在每台设备使用新密码重新登录 |
| 账号安全页会话不消失 | 当前会话本身仍在活动 | 使用撤销其他会话退出其他设备；退出本端使用退出按钮 |
| 管理员看不到签发链接 | 账号已停用或目标不合法 | 先恢复账号；确认目标是普通账号；管理员账号不可作为目标 |
| 窄屏操作按钮溢出 | 旧缓存或未加载新样式 | 强制刷新；确认构建包含 720px 卡片规则；仍异常时记录视口与浏览器版本 |

## 6. 回滚与数据边界

- 本票只改前端页面与样式，没有数据库迁移；回滚代码即可恢复旧页面，账号、链接、会话和审计数据不受影响。
- 不在 backend/data 或 main/backend/data 上执行测试、迁移或清理；浏览器脚本只使用 .scratch/t76-browser 下的隔离临时数据库。
- 一次性链接、密码和会话 token 不应出现在日志、截图、工单或聊天记录中；发现泄露时立即由管理员停用账号、重新签发链接并撤销会话。
- 本票没有自动删除账号、事件或链接的后台任务；保留期和清理仍按既有运维流程执行。
