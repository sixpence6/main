# R1 账号停用、恢复与安全事件查看操作说明

- **适用版本**：v3 R1，ticket #58（代码提交 d823592、982a28f 及之后的文档提交）
- **适用对象**：已登录管理员；普通用户可查看本人必要安全事件
- **前置阶段**：C0 备份与维护基线（#54）、R1 首管理员与登录（#55）、账号创建与一次性链接（#56）、本人改密与多端会话（#57）已合并
- **状态**：本说明只覆盖管理员停用／恢复普通账号与最小安全事件视图；不覆盖业务对象数据隔离、后台生成任务归属或品牌化界面

## 1. 范围与硬边界

本操作允许管理员：

1. 在账号管理页停用一个普通账号。
2. 在账号管理页恢复一个已停用的普通账号。
3. 查看必要的账号管理与安全审计事件。

明确不允许：

- 停用、恢复或读取管理员账号；管理员账号只通过本机维护命令管理。
- 删除账号、修改邮箱、查看或代填密码、代替用户登录、直接把普通用户提升为管理员。
- 修改、删除、清空或导出审计记录；系统不提供此类网页接口。
- 直接改数据库绕过账号状态、会话撤销或审计。
- 使用真实业务数据库演练停用／恢复；演练必须使用临时数据目录。

## 2. 前置条件

| 项 | 要求 |
|---|---|
| 服务版本 | 已部署包含 #58 的构建（迁移仍为 0004 或更高） |
| 管理员 | 已通过本机交互终端完成 init-admin，且当前可正常登录 |
| 网络边界 | 仅可信内网／局域网；不得直接暴露公网 |
| 浏览器 | 支持 ES2020 和 SameSite Cookie 的现代浏览器 |
| 数据 | 操作前确认目标账号是普通账号；生产演练使用临时数据根 |

本票不新增数据库迁移；账号禁用字段、会话纪元和账号链接表已在 #55／#56 中建立。升级只需部署代码并执行常规 alembic upgrade head。

## 3. 操作步骤

### 3.1 管理员登录与进入账号管理

1. 打开 APP_PUBLIC_URL 下的 /login。
2. 使用管理员邮箱与密码登录。
3. 在页头进入“账号管理”（/admin/accounts）。

### 3.2 停用普通账号

1. 在账号表格中找到目标普通账号，确认状态为“待设置密码”或“正常”。
2. 点击“停用账号”。
3. 确认后页面提示：“账号已停用，其登录会话和未使用的一次性链接已撤销。”
4. 列表状态变为“已停用”；管理安全事件面板新增 account_disabled 事件，包含 before／after 与会话／链接撤销数量。

停用后立即生效：

- 该账号全部现有浏览器会话失效；下一请求返回 401。
- 该账号全部未使用 setup／reset 链接失效；打开或提交均返回统一“链接无效或已过期”。
- 新登录被拒绝，且不会提示账号是否存在。
- 本票只保证新的 HTTP 请求被拒绝；后台生成任务、已发出的模型调用与发布截断由 #62 处理。不要把停用理解为对已发远端请求的取消。

### 3.3 恢复普通账号

1. 在账号表格中找到“已停用”的普通账号。
2. 点击“恢复账号”。
3. 确认后页面提示：“账号已恢复；旧会话和旧链接不会恢复，本人需重新登录。”
4. 列表状态恢复为“正常”或“待设置密码”。

恢复语义：

- 旧会话、旧 Cookie、旧 CSRF 与旧一次性链接都不会复活。
- 原密码仍有效，但必须通过 /login 重新登录。
- 若该账号从未设置密码，恢复后仍是“待设置密码”；需重新签发 setup 链接，不能直接登录。
- 恢复不会自动重启后台任务、重新发起模型调用或重新提交生成；这些需要用户在新会话中手动操作。

### 3.4 查看安全事件

管理员视图：

1. 在 /admin/accounts 下方查看“安全事件”面板。
2. 可选择事件类型、结果、操作者、对象和状态变化。
3. 未知账号只显示“未知账号（ref）”，不会显示原始 ID 或邮箱。
4. 事件中的 before／after 只含 status、is_admin、is_disabled、session_epoch；detail 只含 purpose、数量、方法等白名单字段。

普通用户视图：

1. 登录后进入“账号安全”（/account/security）。
2. 在“账号安全事件”面板查看与本人相关的登录、改密、链接、停用／恢复与权限拒绝事件。
3. 页面只显示事件类型、结果、时间、操作者与原因；不显示事件 ID、会话 ID、他人邮箱、密码、令牌或内容。

两类视图均为只读，最多显示最近 100 条；完整 90 天保留清理在发布阶段执行。

## 4. 安全边界

| 边界 | 行为 |
|---|---|
| 授权 | 只有已登录管理员可停用／恢复普通账号；普通用户调用返回 403；管理员目标返回 404 ACCOUNT_NOT_FOUND |
| 状态分离 | is_disabled 独立于是否设置密码；恢复不会让 pending_setup 跳过设置 |
| 会话撤销 | 停用递增 session_epoch 并撤销全部会话；下一请求立即失效 |
| 链接撤销 | 停用撤销全部未使用 setup／reset 链接；恢复不复活旧链接 |
| 审计原子性 | 状态变更与审计同事务；审计写入失败则整体回滚 |
| 审计内容 | 稳定账号 ID、操作者、对象、结果、reason、source_ref、before／after（白名单）；不含密码、令牌、Cookie、请求体或用户创作内容 |
| 权限拒绝 | 已登录普通用户调用管理端记录 permission_denied；审计故障不改变 403，也不会放行 |
| 视图秘密隔离 | 普通用户仅见本人事件；管理员见必要管理与安全事件，不见他人创作、密码、令牌或密钥 |
| 前端 | 所有状态变更带 CSRF 与 Origin；GET 不改状态；私有响应 no-store／no-referrer |

## 5. 常见失败与处理

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 停用／恢复返回 403 FORBIDDEN | 当前账号不是管理员，或管理员会话已失效 | 使用管理员账号重新登录；不要通过前端伪造角色字段 |
| 返回 404 ACCOUNT_NOT_FOUND | 目标不存在，或目标是管理员 | 核对账号列表；管理员账号只能走本机维护流程 |
| 返回 422 | 请求格式错误；例如普通用户在创建账号请求中夹带 is_admin／role | 去掉非法字段；客户端角色字段不参与授权 |
| 返回 503 AUTH_UNAVAILABLE／AUTH_BUSY | 认证或数据库依赖暂时不可用 | 稍后重试；不要绕过服务直接改库 |
| 停用成功但用户仍能打开旧页面 | 浏览器有缓存；下一业务请求应 401 | 刷新页面；若仍可访问，按事故流程检查会话撤销与审计 |
| 恢复后用户仍无法登录 | 账号仍是 pending_setup，或密码已被重置 | 重新签发 setup 链接，或使用正常密码登录；不要复用旧链接 |
| 审计写入失败 | 数据库／审计依赖故障 | 状态变更已回滚；恢复依赖后重试，不要手工补写审计 |
| 安全事件为空 | 事件超出 100 条、账号无相关事件或保留策略尚未执行 | 使用管理视图核对；90 天保留清理属发布阶段 |
