# R1 本机首管理员遗失恢复

本文只说明 ticket #57 提供的**本机维护入口**。它不提供网页找回密码、邮件重置、远程恢复接口或任何管理员代登能力。

## 1. 适用范围与硬边界

当唯一首管理员遗失密码，或首管理员账号被误禁用而无法登录时，由能够物理或受控访问服务器本机的维护者执行：

```powershell
cd main/backend
python -m app.auth.cli recover-admin
```

允许的效果：

- 将指定管理员账号的密码重置为新密码。
- 清除该管理员账号的禁用状态。
- 撤销该账号全部现有会话与全部未使用账号链接。
- 递增会话纪元，旧会话下一请求立即失效。
- 写入 `admin_recovered` 审计，actor 为 `local_maintainer`。

明确不允许：

- 通过 HTTP、网页表单、邮件、短信或聊天机器人恢复首管。
- 通过命令行参数传入明文密码；密码只能在 TTY 中交互输入。
- 恢复普通账号、提升普通账号为管理员或查看任何旧密码。
- 直接修改数据库、删除审计或绕过本机 TTY 限制。
- 用真实生产数据做演练；演练必须使用临时数据目录。

## 2. 前置条件

| 项 | 要求 |
|---|---|
| 服务版本 | 已部署包含 ticket #57 的构建 |
| 数据库 | 已执行 `alembic upgrade head`；本票无新迁移 |
| 执行位置 | 服务器／维护者本机的真实交互终端；stdin 与 stdout 都必须是 TTY |
| 数据库路径 | 与正式服务使用同一 `DATA_DIR`／数据库配置 |
| 服务状态 | 建议先停止应用进程，避免并发写入与运维窗口外的会话变更；至少确认没有其他管理员操作 |
| 管理员 | 未指定邮箱时数据库必须恰好有一个管理员；指定邮箱时该邮箱必须是管理员 |
| 依赖 | `argon2-cffi` 与弱口令表可用；不可用时命令 fail-closed |

## 3. 操作步骤

### 3.1 停止服务并确认配置

1. 按发布运维流程停止后端服务，确认没有正在执行的生成任务或维护窗口。
2. 确认当前 shell 使用的 `DATA_DIR`／数据库 URL 指向要恢复的实例。
3. 确认执行账户对数据目录有读写权限。

### 3.2 执行恢复

只有一个管理员时可不带邮箱：

```powershell
python -m app.auth.cli recover-admin
```

存在多个管理员时必须指定目标邮箱：

```powershell
python -m app.auth.cli recover-admin admin@example.com
```

交互过程：

1. 如未提供邮箱，命令提示输入管理员邮箱。
2. 命令使用 `getpass` 读取新密码两次，终端不回显；没有 `--password`。
3. 密码要求至少 15 个、最多 128 个 Unicode code point；允许空格与 Unicode；命中版本化弱口令表会被拒绝。
4. 成功后打印管理员邮箱与不可变 UUID，并提示全部会话和未使用凭证已撤销。
5. 命令不会自动启动服务，也不会自动建立登录会话。

### 3.3 恢复后验证

1. 启动服务。
2. 打开 `APP_PUBLIC_URL` 下的 `/login`，用管理员邮箱和新密码登录。
3. 确认旧密码失败、旧会话下一请求 401。
4. 在 `/account/security` 检查会话列表，只应看到本次登录会话。
5. 确认审计中存在 `admin_recovered` 事件，且不含密码或 token。

## 4. 安全语义

| 边界 | 行为 |
|---|---|
| 入口 | 仅本机 CLI；无 HTTP 路由；OpenAPI 无恢复路径 |
| TTY | 非交互管道／重定向拒绝，退出码 2 |
| 密码输入 | `getpass` 两次；无命令行密码参数；不回显、不写日志 |
| 目标选择 | 未指定邮箱时必须恰好一个管理员；指定时必须是管理员 |
| 凭据撤销 | 全部会话与全部未使用账号链接立即撤销；会话纪元递增 |
| 禁用状态 | 清除 `is_disabled`、`disabled_at`、`disabled_by`，使管理员可重新登录 |
| 审计 | `admin_recovered`，actor `local_maintainer`，记录方法与会话／链接撤销范围；敏感变更与审计同事务 |
| 原子性 | 哈希或审计失败时密码、纪元、会话和链接撤销整体回滚 |
| 网络提权 | 不存在可调用的维护 API；客户端角色、owner 参数或管理页面均不能触发 |

## 5. 常见失败与处理

| 现象 | 含义／处理 |
|---|---|
| “未找到唯一的首管账号，已拒绝恢复。” | 无管理员、多个管理员但未指定邮箱、邮箱不是管理员或邮箱格式不合法；核实账号后重试 |
| “本机维护命令只能在本机交互终端中运行。” | 在管道、重定向或非 TTY 环境执行；改到服务器真实终端 |
| 密码不符合要求 | 按提示修正；不会写入账号 |
| 两次密码不一致 | 重新执行；不会写入账号 |
| 认证组件不可用 | 修复 `argon2-cffi`／弱口令表依赖；命令 fail-closed |
| 数据库迁移不完整／不可写 | 先按运维流程执行迁移并检查数据目录权限 |
| 恢复后仍无法登录 | 确认启动的是同一 `DATA_DIR`；检查账号是否仍被其他流程禁用；不要手工改库 |
