## Spec 初审

3 项已通过认证 API、临时 SQLite 和脚本适配器复现的缺陷：

1. P1：视觉关键词被当成制作依据。“我觉得冷白背景比较适合钢笔主图”可能启动制作；待确认提示词时“我喜欢这个背景”可能替换快照并改变意图及用量。
2. P2：咨询关键词对子串的匹配误拦明确制作。“你可以帮我做一张钢笔主图”和文案含“为什么选择我们”的制作请求被当成闲聊。
3. P2：生成中“我很喜欢这个文案”仅因含文案名词被持久化为修改意见。

修复要求：依据整句请求与当前上下文识别动作，视觉名词、模型补齐的 brief、普通偏好和赞赏不能独自授权；礼貌请求和图片文案不应被咨询规则吞掉。
